# Focus Timer

Pomodoro/focus sessions plus Toggl and Clockify time tracking.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Pomodoro/focus sessions plus Toggl and Clockify time tracking via the `pomo` keyword.

![Focus Timer results in Alfred](images/pomo.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-focus-timer-<version>.alfredworkflow
```
